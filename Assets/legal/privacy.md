# DomeOS AI 隐私政策

**版本：1.0.0**
生效日期：2026-10-05
最近更新：2026-10-05

本政策说明 DomeOS AI（以下简称“本软件”）如何处理与您有关的信息。请在开始使用前完整阅读。

本软件是一款**运行在您本机的桌面客户端**。它没有运营方的服务器，我们不会、也无法从远端收集您的任何数据。所有信息的产生、存储与去向都在您这台电脑上，以及由您自行选择并配置的第三方 AI 服务商处。

---

## 一、我们处理哪些信息，以及为什么

### 1. 您在本机产生的数据

以下内容**只保存在您的电脑上**，保存在 %APPDATA%\\DomeOS AI Agent Dev 目录中，不会上传给本软件的开发者：

- **配置信息**：您选择的服务商、接口地址、模型名、系统提示词、权限设置、界面偏好。
- **对话记录**：您与模型的往来内容，用于在左侧列表里展示历史对话。
- **工作区索引**：您选定的工作区路径及其目录结构，用于在侧栏显示文件树。

您可以随时在设置中打开该目录查看、备份或直接删除这些文件。卸载本软件时，该目录默认保留；如需彻底清除，请手动删除。

### 2. 您的 API 密钥

您自行申请并填入的 API 密钥**以明文形式保存在上述本机配置文件中**，仅在向您指定的接口发起请求时用作身份凭据。

密钥不会发送给除该服务商以外的任何一方，也不会回传给本软件的开发者。**请自行妥善保管您的电脑账户；任何能读取该配置文件的程序都能读到这把密钥。**

### 3. 发送给第三方 AI 服务商的内容

当您发起一次对话时，本软件会把**完成任务所必需的内容**直接发送到您配置的接口：

- 您的输入，以及本轮对话的历史上下文；
- 您配置的系统提示词；
- 当模型要求调用工具时：工具名称与参数，以及**工具执行后的结果**。

其中的“工具执行结果”可能包含您工作区内的文件内容、命令输出、目录列表。**发送范围完全由您在对话中给出的指令决定。** 本软件无法替您判断哪些文件内容敏感，请在让它处理文件前自行确认。

第三方服务商如何处理这些数据，适用**该服务商自己的隐私政策**，与本软件无关，我们无法控制也无法干预。请在使用前阅读您所选服务商的条款。

### 4. 联网检索

本软件内置联网搜索。启用时，您的**搜索关键词**会发送到公开的搜索引擎（Bing、百度、360、DuckDuckGo、Brave 等），被打开的网页内容会回传给模型。搜索关键词同样会先经过您配置的 AI 服务商。

### 5. 我们不收集什么

我们**不收集**：您的姓名、手机号、邮箱、身份证件、通讯录、位置、剪贴板内容、浏览器历史、其它程序的运行情况。

本软件**不包含**任何统计埋点、崩溃上报、广告或用户画像组件。它不会在您不知情时向开发者回传任何信息。

---

## 二、本机权限与操作范围

本软件可以读写文件、执行命令。这些能力的边界由您在设置中选定：

- **仅工作区内**：所有文件操作被限制在您指定的工作区目录内，越界请求会被拒绝。
- **整个电脑**：可以访问本机所有磁盘与路径，并执行任意命令，其权限等同于您的 Windows 用户账户。

**危险操作前的确认由您决定**：您可以要求每次写文件、删除、执行命令前先询问，也可以选择自动批准。选择自动批准即表示您接受由此产生的一切后果。

> 请特别注意：在“整个电脑 · 完全权限”下，模型的一次误判可能造成不可恢复的损失。做出这个选择前，请确认您理解其含义。本软件**无法撤销**已执行的删除或覆盖操作。

---

## 三、Cookie 与同类技术

本软件的界面不使用 Cookie，不进行跨站跟踪，不含第三方分析或广告脚本。

联网检索与网页读取功能在请求外部网站时会携带常规的 HTTP 请求头，这些网站可能依其自身政策记录访问日志。

---

## 四、信息的存储与保护

- **存储位置**：全部在本机 %APPDATA%\\DomeOS AI Agent Dev，不经过任何中转服务器。
- **传输**：与 AI 服务商、搜索引擎之间使用 HTTPS；实际强度取决于对方的接口。
- **保护**：本软件不做额外的加密存储。请依赖 Windows 账户权限、磁盘加密（如 BitLocker）来保护本机数据。

由于数据不离开您的设备，我们无法、也不会对您本机的数据安全作出承诺或承担保管义务。

---

## 五、您的权利与操作方式

您对上述本机数据拥有完全的控制权，可以随时：

- **查阅与导出**：在设置中打开配置目录，直接查看或复制这些文件。
- **更正**：在设置界面中修改任何配置项；对话内容可在界面中重命名或删除。
- **删除**：删除单条对话、清空全部对话，或直接删除配置目录。
- **撤回授权**：清空 API 密钥、关闭联网搜索、把权限收回“仅工作区内”。
- **拒绝**：卸载本软件即可终止全部处理行为。

由于我们并不持有您的数据，**无需也无法受理查阅、更正、删除个人信息的申请**——这些操作都在您自己手上。

## 六、未成年人

本软件面向成年人。若您未满 18 周岁，请在监护人陪同下阅读本政策，并在取得监护人同意后使用。本软件不面向未满 14 周岁的儿童，我们不会主动收集其任何信息。
